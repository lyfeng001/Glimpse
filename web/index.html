接管电脑上的会话

Glimpse 无法直接接管已经打开的终端窗口，而是新启动一个进程继续同一段对话。接管前请先在电脑上关闭原来的 claude / codex，否则两边会各自写入、对话分叉。

模型与模式

添加机器

Hub 会用这台电脑已有的 SSH 密钥连接（不支持密码登录），远端需要 Python 3.8+。Claude / Codex 的启动命令沿用本机预设，之后可在 config.json 修改。

安装为 App

添加到主屏幕后，Glimpse 会像原生 App 一样全屏打开，有自己的图标，并且可以接收推送通知。

  1. 1在 Safari 底部（iPad 在右上角）点 分享
  2. 2向下滑动，选择 添加到主屏幕
  3. 3点右上角“添加”，然后从主屏幕图标打开 Glimpse，再到设置里开启通知
  1. 1Android Chrome：点右上角 ⋮ → 安装应用（或“添加到主屏幕”）
  2. 2电脑上的 Chrome / Edge：点地址栏右侧的 安装 图标
  3. 3安装后从桌面或启动器打开 Glimpse

没有 App Store 版本：添加到主屏幕的网页 App 就是 Glimpse 的 App 形态。

开关控制首页和会话页显示哪些插件，箭头调整顺序。

开关决定会话底部显示哪些键，箭头调整顺序。自定义键的写法：^X 是 Ctrl-X，\e 是 Esc，\r 是回车，\t 是 Tab，\x1b 这种是任意字节；其他字符原样发送。

同一个项目的所有 Claude Code / Codex 会话共享一份长期记忆（AMem）：助手会读取之前的结论，并把确认过的结论存下来。超过存储上限时，会先清理最旧的工具输出。

自动均衡

参与均衡的 Key

关掉的 Key 不会被自动选中，但你仍然可以手动给会话指定它。支持直接切换的会话（Claude Code 和用自定义中转的 Codex）换 Key 时不重启，其他会话会重启并恢复对话。
